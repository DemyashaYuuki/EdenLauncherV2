# Model geometry attribution

The XML model definitions in this directory come from the model library shipped with
MCSkin3D 1.6.0.603, by Paril and contributors: https://github.com/Paril/mcskin3d .
They are redistributed as editable geometry sources under the accompanying GPL v3
license. Original Author/Description fields are retained, including Mojang attribution.
No skins, Minecraft texture artwork, executable or private skin library is included.
The editor and its native XML/TCN importer are new EdenLauncher implementations.
