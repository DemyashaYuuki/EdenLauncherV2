# EdenLauncher 2.0

Брендированный лаунчер для проекта [EdenWorld](https://edenworld.fun/), построенный на актуальной стабильной ветке AstralRinth / Theseus.

## Что добавлено

- фирменная главная страница EdenWorld с локальными логотипом и фоном;
- быстрая потоковая загрузка и установка `EdenWorld 1.21.11.mrpack`;
- отображение прогресса, автоматическое создание профиля и переход к нему;
- быстрый переход на сайт, в [Telegram](https://t.me/EdenWorldMC) и [Discord](https://discord.gg/WBTUMKuBTa);
- RF-режим, использующий прямой CDN-маршрут Google Drive и системные настройки прокси;
- фиолетовая тема EdenWorld, режимы «Как в системе», Mica, «Асуна», Error и редактор собственных тем;
- локальный сервер EdenWorld с автоматической Java, выбором ОЗУ, встроенной консолью и инструкцией подключения;
- автоматическая проверка и установка обновлений EdenLauncher с GitHub.

RF-режим не передаёт логины, токены или другую авторизационную информацию через публичные бесплатные прокси. Для сетевых запросов лаунчер использует доступные API/CDN и системный HTTP/SOCKS-прокси пользователя. Такой вариант безопаснее случайных открытых прокси и сохраняет совместимость с корпоративными и локальными сетями.

## Разработка

Требования: Node.js 24.15+, pnpm 10.33.2, Rust из `rust-toolchain.toml`, системные зависимости Tauri 2.

```bash
pnpm install --frozen-lockfile
pnpm app:dev
```

Сборка установщика:

```bash
pnpm app:build
```

## Архитектура

- `apps/app-frontend` — интерфейс Vue 3;
- `apps/app` — оболочка Tauri 2;
- `packages/app-lib` — ядро лаунчера Theseus;
- `apps/app-frontend/src/helpers/edenworld.ts` — загрузка и установка сборки EdenWorld;
- `apps/app-frontend/src/pages/Index.vue` — главная страница EdenLauncher.
