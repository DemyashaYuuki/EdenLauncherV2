# EdenLauncher 2.0

Брендированный лаунчер для проекта [EdenWorld](https://edenworld.fun/) на базе Theseus.

## Что добавлено

- фирменная главная страница EdenWorld с локальными логотипом и фоном;
- быстрая потоковая загрузка и установка `EdenWorld 1.21.11.mrpack`;
- отображение прогресса, автоматическое создание профиля и переход к нему;
- быстрый переход на сайт, в [Telegram](https://t.me/EdenWorldMC) и [Discord](https://discord.gg/WBTUMKuBTa);
- совместимые CDN-маршруты Google Drive и системные настройки прокси используются автоматически;
- фиолетовая тема EdenWorld, режимы «Как в системе», Windows 10, «Асуна», Error и редактор собственных тем;
- рабочий стол Windows 10 с перемещаемыми ярлыками, контекстными свойствами и оконным режимом разделов;
- аккаунт и друзья Modrinth, голосование за EdenWorld, головы игроков в списке онлайна и пасхалка `pilot`;
- автоматическая проверка и установка обновлений EdenLauncher с GitHub.

## Оформление «Портал в EdenWorld»

- оболочка с боковой навигацией (главная, библиотека, каталог, скины, друзья, загрузки), статусом сервера и карточкой игрового аккаунта; на окнах уже 1280 px навигация сворачивается в полосу значков;
- режимы Eden / Portal (тёмный и светлый), «Асуна» / Bloom, Error / Signal, Windows 10 и своя тема используют общие цветовые роли из `store/theme.ts` и примитивы из `assets/stylesheets/eden.scss`;
- главная кнопка запуска отражает реальное состояние: установка → играть → запуск → игра запущена;
- экран «Загрузки» показывает задания установки, фоновые операции и обновление лаунчера с отменой, повтором и историей;
- заставка показывает прогресс только когда он известен, мастер первого запуска рекомендует память по объёму ОЗУ устройства;
- сохранённые темы, акценты и фоны переносятся без сброса; прежний акцент по умолчанию заменяется новым, выбранный пользователем цвет сохраняется.

Иллюстрации и значки — в `apps/app-frontend/src/assets/eden` (см. README в этой папке).

Лаунчер не передаёт логины, токены или другую авторизационную информацию через публичные бесплатные прокси. Для сетевых запросов используются доступные API/CDN и системный HTTP/SOCKS-прокси пользователя. Такой вариант безопаснее случайных открытых прокси и сохраняет совместимость с корпоративными и локальными сетями.

## Разработка

Требования: Node.js 24.15+, pnpm 10.33.2, Rust из `rust-toolchain.toml`, системные зависимости Tauri 2.

```bash
pnpm install --frozen-lockfile
pnpm app:dev
```

Сборка установщика:

```bash
pnpm app:build
```

## Архитектура

- `apps/app-frontend` — интерфейс Vue 3;
- `apps/app` — оболочка Tauri 2;
- `packages/app-lib` — ядро лаунчера Theseus;
- `apps/app-frontend/src/helpers/edenworld.ts` — загрузка и установка сборки EdenWorld;
- `apps/app-frontend/src/pages/Index.vue` — главная страница EdenLauncher;
- `apps/app-frontend/src/components/ui/eden` — общие элементы оформления (боковая панель, знак EW, значки);
- `apps/app-frontend/src/composables/eden` — общее состояние сервера, установки EdenWorld и загрузок.
