# EdenLauncher 2.10.1

Брендированный лаунчер для проекта [EdenWorld](https://edenworld.fun/) на базе Theseus.

## Исправления 2.10.1

- Редактор, библиотека и плащи находятся во вкладке «Скины»; отдельный пункт «Мастерская» убран.
- Аккаунты обновляются после входа, переключения, удаления, возврата в редактор и фокуса окна.
- Ошибка чтения аккаунтов показывает сообщение и кнопку повтора, а не предложение добавить аккаунт.
- Активный офлайн-аккаунт доступен для привязки EdenSkinBridge; старый гардероб Microsoft открывается из редактора.
- CI проверяет обновление с опубликованной 2.10.0 и сохранность контрольных файлов.
- Настройки мастерской: видимые переключатели с подписями «Включено / Выключено» и пояснениями, проценты прозрачности сетки, сворачиваемый список клавиш.

## Возможности 2.10

- Мастерская скинов: рисование в 3D/2D, Classic/Slim/Legacy, слои, палитры, инструменты, история и HD.
- Проекты, библиотека, корзина, восстановление и защита несохранённой работы при закрытии.
- Применение к выбранному Microsoft-аккаунту и только принадлежащие ему плащи.
- EdenSkinBridge для Purpur и Velocity: SkinsRestorer, текущий nLogin и VeloAuth следующего сезона.
- Для Ely.by пока используется экспорт PNG и официальный сайт; прямое OAuth-применение не реализовано.
- [Возможности и ограничения](docs/SKIN-STUDIO-2.10.md), [установка плагинов](server/eden-skin-bridge/docs/INSTALL.md).

Плагины нужно настроить отдельно. В сборку не входят VeloAuth, nLogin, SkinsRestorer или чужие скины.
Репозиторий содержит overlay поверх AstralRinth `80a011e8008ce4f0fd828b98a4a5a2fdcbc01c86`.
Полная последовательность подготовки исходников и сборки записана в `.github/workflows/build-windows.yml`.

## Обновление 2.9.1

- обновлённые окна настроек и входа в аккаунты;
- отдельный сохраняемый переключатель «Помехи и Glitch» для Error / Signal;
- официальный WebView2 bootstrapper включён в Windows-установщик без изменения подписи Microsoft;
- CI проверяет подпись и SHA-256 WebView2 до упаковки и соответствие файла внутри готового EXE;
- CI проверяет установку EXE/MSI, запуск процесса, переход с 2.9.0 и сохранность тестовых данных при удалении;
- помощник обновления больше не задаёт `ExecutionPolicy Bypass`; проверка SHA-256 загрузки сохранена.
- версия Rust-приложения синхронизирована с релизом вместо `1.0.0-local`, CI проверяет их соответствие.

Если WebView2 Runtime отсутствует, bootstrapper установит его с серверов Microsoft: для этого нужен интернет. Режим `skip` не используется. Сам лаунчер и его установщики остаются без платного сертификата. Это обновление не обещает отсутствия всех предупреждений SmartScreen или песочниц. Протокол выполненных проверок и контрольные суммы публикуются рядом с установщиками.

## Что добавлено

- фирменная главная страница EdenWorld с локальными логотипом и фоном;
- быстрая потоковая загрузка и установка `EdenWorld 1.21.11.mrpack`;
- отображение прогресса, автоматическое создание профиля и переход к нему;
- быстрый переход на сайт, в [Telegram](https://t.me/EdenWorldMC) и [Discord](https://discord.gg/WBTUMKuBTa);
- совместимые CDN-маршруты Google Drive и системные настройки прокси используются автоматически;
- фиолетовая тема EdenWorld, режимы «Как в системе», Windows 10, «Асуна», Error и редактор собственных тем;
- рабочий стол Windows 10 с перемещаемыми ярлыками, контекстными свойствами и оконным режимом разделов;
- аккаунт и друзья Modrinth, голосование за EdenWorld, головы игроков в списке онлайна и пасхалка `pilot`;
- автоматическая проверка и установка обновлений EdenLauncher с GitHub.

Лаунчер не передаёт логины, токены или другую авторизационную информацию через публичные бесплатные прокси. Для сетевых запросов используются доступные API/CDN и системный HTTP/SOCKS-прокси пользователя. Такой вариант безопаснее случайных открытых прокси и сохраняет совместимость с корпоративными и локальными сетями.

## Разработка

Требования: Node.js 24.15+, pnpm 10.33.2, Rust из `rust-toolchain.toml`, системные зависимости Tauri 2.

```bash
pnpm install --frozen-lockfile
pnpm app:dev
```

Сборка установщика:

```bash
pnpm app:build
```

## Архитектура

- `apps/app-frontend` — интерфейс Vue 3;
- `apps/app` — оболочка Tauri 2;
- `packages/app-lib` — ядро лаунчера Theseus;
- `apps/app-frontend/src/helpers/edenworld.ts` — загрузка и установка сборки EdenWorld;
- `apps/app-frontend/src/pages/Index.vue` — главная страница EdenLauncher.
