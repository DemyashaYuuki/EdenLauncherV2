# EdenLauncher 2.10.2 — Мастерская скинов

Редактор открывается во вкладке «Скины» бокового меню; отдельного пункта «Мастерская» нет.
Список аккаунтов синхронизируется после входа, переключения и удаления, при возврате
в редактор и фокусе окна. При ошибке загрузки есть повторная попытка.
Гардероб Microsoft доступен по кнопке в редакторе для выбранного Microsoft-аккаунта.
Проекты и PNG сохраняются локально независимо от
типа аккаунта. Применение внешнего вида требует отдельного подтверждения цели.

## Установка на EdenWorld в 2.10.2

Автоматическое применение на сервере временно отключено. Есть отдельная кнопка
**«Сохранить файл скина (.png)»**, она работает и без аккаунта в лаунчере.

1. Сохрани текстуру PNG 64×64 или 64×32 из модели игрока Classic/Slim.
2. Открой [официальный загрузчик SkinsRestorer](https://skinsrestorer.net/upload).
3. Выбери PNG, укажи Classic/Slim. Бесплатный способ Axolotl предлагает поддерживаемые
   плащи из списка; произвольный PNG-плащ загрузить нельзя.
4. Нажми Generate /skin url и скопируй всю полученную команду с кавычками и моделью.
5. Авторизуйся на EdenWorld и выполни команду в игровом чате. Дождись успешного ответа,
   затем проверь результат после перезахода. Если прав нет — попроси администратора.

Локальный путь к файлу не является URL. PNG нужен для игры; для дальнейшего
редактирования отдельно сохраняй проект .edenskin. Лаунчер сам файлы на сайт не отправляет.
Справка: https://skinsrestorer.net/docs/features/skin-upload.

«Не сохранять» в запросе выхода отбрасывает рабочие изменения и закрывает окно;
«Отмена» возвращает к редактору. Ошибка сохранения не закрывает окно и не удаляет документ.

## Возможности

| Область | Реализовано |
| --- | --- |
| Рисование | Настоящие 3D и 2D, разделённый экран, карандаш, ластик, пипетка, заливка, шум, осветление/затемнение, штамп и выделение |
| Кисти и цвет | Размер и форма кисти, непрозрачность, накопление, симметрия, RGBA/HSV/HEX, смена основного и второго цвета, палитры GPL/ACO/ACT/SWTCH/JSON |
| Модели | Classic, Slim, Legacy, основные и внешние слои, скрытие частей, 48 геометрических моделей MCSkin3D, импорт Techne XML/TCN |
| Форматы | PNG, проекты `.edenskin`, преобразование Legacy/Modern и ширины рук с отменой, изменение размера, HD до 4096 пикселей |
| Библиотека | Несколько документов, папки, копирование, перемещение, переименование, корзина и восстановление, свой каталог, сохранение всех проектов |
| Просмотр | Сетка UV, масштабирование, перемещение, вращение, освещение, фон и трава, анимация, снимок и буфер обмена, отдельное окно предпросмотра |
| Удобство | Русский/английский язык, настраиваемые сочетания клавиш, восстановление работы, предупреждение при закрытии с несохранёнными изменениями |
| Microsoft | Загрузка в выбранный аккаунт через Minecraft Services; только принадлежащие аккаунту плащи; подтверждение текстуры, модели и плаща после ответа сервиса |
| Ely.by | Экспорт PNG и открытие официальной страницы загрузки. **Прямое применение через OAuth в этой версии не реализовано.** |
| Офлайн / EdenWorld | Экспорт PNG и инструкция ручной установки через SkinsRestorer. Серверная автосинхронизация временно отключена |

Внешние слои и прозрачность не создают новые игровые права. Произвольный PNG-плащ можно
редактировать и экспортировать, но применять к обычному клиенту Minecraft нельзя. Для
установки через SkinsRestorer используй только предложенные сервисом поддерживаемые
плащи. Выбор плаща не передаёт право владения в аккаунт Microsoft. Клиентский мод не требуется.

## Ограничения и проверка

Это новый редактор с аналогичными рабочими инструментами, а не запуск старого MCSkin3D.
Полное совпадение всех редких сценариев старой программы не подтверждено. Импорт Techne
пока выбирает первую модель документа; неизвестные фигуры и planes пропускаются с
предупреждением. Сам MCSkin3D также не переводит planes в отображаемую геометрию в
`Models/ModelFormatTCN.cs`. В поставку входят только XML-геометрия и оригинальные скины
Eden, без исполняемого файла MCSkin3D и чужой библиотеки скинов.

Ely.by публикует OAuth scope `change_skin`, а сайт использует отдельные маршруты загрузки.
Совместимость этих маршрутов с токенами стороннего лаунчера не подтверждена. Поэтому
экспорт здесь честно обозначен как запасной путь, а не как автоматическая установка.
Пароли и cookies браузера редактор не запрашивает.

Проверены движок рисования, UV, история, форматы и небезопасные входные файлы; отдельно
реальное рисование мышью в Vue-компонентах, undo/redo и сохранение через тестовый файловый
адаптер. Проверка интерфейса использует фиктивные аккаунты и не меняет внешние профили.

Реальные серверные запуски выполнены на изолированных Purpur 1.21.11 build 2568 и 26.3 build
2654 с настоящим SkinsRestorer 15.12.6. Проверены загрузка, health, запрет применения без
токена и корректная остановка. VeloAuth проверен контрактным тестом по предоставленному
JAR 1.6.2-offline.2; состояния входа/2FA/выхода проверяются с тестовыми объектами API.
Полная игровая сессия через настоящий VeloAuth/nLogin и генерация MineSkin с ключом
оператора не проверялись. Реальное применение к Microsoft/Ely.by и Linux-запуск также
не выполнялись. Native-пакеты и проверки Windows собираются в GitHub Actions.

Не следует трактовать компиляцию или модульный тест как подтверждение живой смены скина.
Точные результаты, контрольные суммы и ограничения каждой сборки находятся в протоколе
проверок и SHA256SUMS рядом с установщиками.

## Серверный плагин (автосинхронизация приостановлена)

В 2.10.2 серверные команды IPC не зарегистрированы, кнопки привязки и применения скрыты.
Ниже сохранена документация экспериментального моста для дальнейшей доработки.
Наличие JAR в релизе не означает, что интеграция на EdenWorld уже настроена.


См. [инструкцию установки EdenSkinBridge](../server/eden-skin-bridge/docs/INSTALL.md).
На основной сервер устанавливается Paper JAR, на каждый Velocity-прокси следующего
сезона — Velocity JAR. Нужны настройка авторизации, согласованное хранилище SkinsRestorer
в прокси-сети и HTTPS-адрес API. До настройки лаунчер показывает необходимость привязки.
Автоматической установки плагинов на рабочий сервер нет.

Сохранены проверки официального WebView2, TLS и SHA-256 обновлений из версии 2.9.1.
Отсутствие предупреждений всех песочниц и антивирусов не гарантируется.
